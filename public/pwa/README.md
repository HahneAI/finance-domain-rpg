# PWA install screenshots

The five iOS Safari "Add to Home Screen" tutorial screenshots referenced by
`PwaInstallModal.jsx`. They are served from the site root, so the modal loads
them at `/pwa/<name>`.

Required files (all cropped to remove personal contact info):

- ios-pwa-step-1.jpeg — Safari with three-dots menu button circled
- ios-pwa-step-2.jpeg — Safari menu with "Share" circled
- ios-pwa-step-3.jpeg — Share sheet with "View More" circled (no contacts row)
- ios-pwa-step-4.jpeg — Expanded share sheet with "Add to Home Screen" circled
- ios-pwa-step-5.jpeg — Add to Home Screen confirmation with "Add" circled
